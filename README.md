# Homebrew tap for AI Swaplane

```bash
brew install --cask ramysabryali/tap/ai-swaplane
```

Upgrade with `brew upgrade --cask ai-swaplane`. Remove with `brew uninstall --cask ai-swaplane` (add `--zap` to also delete app data).

The app lives at [ramysabryali/ai-swaplane](https://github.com/ramysabryali/ai-swaplane).
